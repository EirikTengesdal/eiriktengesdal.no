# eiriktengesdal.no

Personal academic website of Eirik Tengesdal, built with [Quarto](https://quarto.org/) and rendered with [babelquarto](https://docs.ropensci.org/babelquarto/). English is the only published language; the Bokmål (`/nb/`), Høgnorsk (`/nn/`, tagged `nn-hognorsk`), Japanese (`/ja/`) and Brazilian Portuguese (`/pt/`) sources are kept in the private CV repository until they have been audited, and are switched on by copying them back and listing them under `babelquarto.languages`.

## Layout

- `_quarto.yml` – site configuration and the babelquarto language list; `_quarto-en.yml` – the English profile (navbar, resources). Profiles and pages for the other languages follow babelquarto's suffix convention (`_quarto-<lang>.yml`, `index.<lang>.qmd`) and arrive from the private repository when audited.
- `cv/` and `publications/` – generated by the private `et-curriculum-vitae` repository (Markdown pages and the short CV PDF). Do not edit by hand; edit the CV data and run its build. Until the CV data has been audited, only the short CV and the peer-reviewed publications are published; Publications is a single page (its overview + subpages return with `build.py --web-pages full` and the commented navbar dropdown in `_quarto-en.yml`).
- `repositories/` – GitHub profile and repository cards drawn live by github-stats-extended (successor of github-readme-stats), as on the previous site.
- `assets/pdf`, `assets/epub`, `assets/xml` – full texts and supplements offered as buttons on the publication entries (file names come from `publications.bib` in the CV repository); `publications/Tengesdal_publications.bib` is generated with the pages.
- `assets/js/pdf-preview.js` – inline PDF preview with PDF.js (works on phones, where an `<iframe>` would download the file); used by the statement pages via `<div class="pdf-preview" data-pdf="…">`.
- `statements/` – hearing statements (*høringssvar*), one `.qmd` per statement plus a listing page.
- `assets/` – images, favicons and PDFs.
- `tools/post_build.py` – adds `hreflang` links, fixes `<html lang>` and stamps the footer with the render date after rendering.

## Build

```bash
Rscript -e 'babelquarto::render_website()'
python tools/post_build.py _site
```

For quick iteration on one language: `quarto preview --profile nb`.

## Deployment

`.github/workflows/publish.yml` renders all languages on every push to `master` (and on `repository_dispatch` from the CV repository) and deploys `_site` to the `gh-pages` branch, which GitHub Pages serves at eiriktengesdal.no (custom domain from `CNAME`).
